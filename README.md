# 当前补丁 v1.205

玩家下载 `归梦v2.26_魔改补丁_v1.205.zip`；维护包用于开发。此版修复v1.204引入的启动闪退，请使用当前版本。

使用：退出游戏，备份存档及原 Lib/game.res，将玩家包 Lib 文件夹覆盖到游戏目录。
排查问题：游戏闪退时，请将 log 文件夹中的日志文件一起提供；重启后上一轮日志见 previous。

修复启动时调用不存在的私有类字段的问题：绘制函数改为闭包直接捕获，取消类描述符读取依赖。保留此前官方编译的等效绘制函数，不恢复错误手工尾段、不关闭JIT或吞错误。当前橙色、统一描边及全部玩法保持。游戏显示魔改版 1.205。

在类描述符不可读方法表的明确有限原语下，旧v204启动state0帧原样复现上传的同名nil方法错误；新冷态/默认JIT/hot通过启动状态、进入状态1、真实分辨率按钮/设置器/窗口构造/完整显示/完整原生帧200帧及GC/类重载。最终两包完整性和玩家资源比对通过。
