# 当前补丁 v1.208（近战手感测试版）

玩家下载 `归梦v2.26_魔改补丁_v1.208.zip`；维护包用于开发。

使用：退出游戏，备份存档及原 Lib/game.res，将玩家包 Lib 文件夹覆盖到游戏目录。
排查问题：游戏闪退时，请将 log 文件夹中的日志文件一起提供；重启后上一轮日志见 previous。

主角普通攻击及战士近战攻击的动作和相关延迟缩短约30%，下一次出手仍按原收招进度/攻击计时放行，不提高持续攻击频率、不额外增加硬直；装备/Buff攻速和各技能冷却保持。包括攻杀、刺杀、半月、翔空、烈火、十方斩、莲月、快刀斩麻，兼容基本剑术实际释放。增益、换位及其他职业技能、佣兵/召唤兽/怪物保持。

仅修改主角当前攻击实例，不改共享技能配置、命中/伤害计算、全局动作结束或已确认配色。游戏显示魔改版 1.208。

普通/hot相关测试通过：实际主角类注册、技能释放/实例/刷新及技能脚本、状态/追击门控/动作和原动画更新，标准测试输入首次伤害0.70→0.49秒。各攻速、帧步长和动作长度下，自动/直接释放各自与旧版接受出手时间表一致；200次代表链攻击和伤害调用次数一致。覆盖冷却、技能交替/自动转换、移动请求及无动画/取消边界。最终两包ZIP完整性和玩家资源比对通过。

图像、地图查询、最终移动/伤害使用明确有限边界；未完成完整主角初始化/原生帧、原始视觉资源、真实地图走砍或Windows客户端实测，不能将受控结果称为实机DPS已验证。此版用于玩家反馈实际手感。没有本版实机杀怪日志，小怪声望不能宣称彻底解决；神兽等既有实测边界保留。每版同步main/downloads，无Release，不覆盖存档，不公开玩家原始日志。
