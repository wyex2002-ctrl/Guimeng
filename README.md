# 当前补丁 v1.213（地图标签启动与异界入口修复版）

玩家下载 `归梦v2.26_魔改补丁_v1.213.zip`；维护包 `Guimeng_v1.213_maintenance.zip` 用于开发。

使用：退出游戏，备份存档及原 Lib/game.res，将玩家包 Lib 文件夹覆盖到游戏目录。
排查问题：游戏闪退时，请将 log 文件夹中的日志文件一起提供；重启后上一轮日志见 previous。

修复v212选择角色进入游戏时地图标签调用不存在的创建文字，以及初始化中断后反复调用resolve的错误。改用插件已有的原字体资源接口，并修正折行调用未导出的string.byte问题。保留标签布局、原圆点配色和所有玩法/DPS。

临时异界之门不再误标神舰，按原入口状态显示“异界＋当前地图名”；正常神舰入口仍显示神舰，到期/切图/同ID复用同步更新。原刷新概率、时长、进入条件、倍率和传送脚本保持。

官方LuaJIT2.0正常/hot专项通过：真实插件安装阶段/受限导出/setfenv，旧版两阶段错误复现，原生地图与字体资源路径，99出口与只读迷阵、布局/缓存及200代表帧。另执行原门生成块、4回调/对话Main与进入动作、到期/切图清理块。两包ZIP完整性、玩家资源与已测哈希匹配。

实体、HP桥接、瞬移、图形及时间触发为有限测试边界；没有完整Windows客户端实测，没有本版实机杀怪日志，小怪声望不能宣称彻底解决。每版同步main/downloads，无Release、不覆盖存档、不公开玩家日志。第八十八节旧API验证结论以第八十九节更正为准。
