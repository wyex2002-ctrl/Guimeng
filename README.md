# 当前补丁 v1.200

玩家下载 `归梦v2.26_魔改补丁_v1.200.zip`；维护包用于开发。

使用：退出游戏，备份存档及原 Lib/game.res，将玩家包 Lib 文件夹覆盖到游戏目录。
排查问题：游戏闪退时，请将 log 文件夹中的日志文件一起提供；重启后上一轮日志见 previous。

游戏内版本文字与窗口标题显示“魔改版 1.200”，窗口保留剧情/难度，内部版本、存档及难度保存机制不改。

7条属性装备名称改为香槟金文字、深棕金描边，装备提示与地面名称均生效。仅针对用户明确授权的7条品质，3～6条、其他字体及属性行保持原显示；原炭灰字体不改，独立别名沿用原生绘制接口。声望、舒适、命中、双召唤及全部既有玩法保持。

普通/hot显示专项通过：真实版本界面/窗口设置器、完整装备提示/生成器、原生地面名称设置、独立与原字体交替绘制及真实富文本解析。42模块非目标一致性、最终两包完整性与资源检查通过。未完成Windows客户端实际视觉效果实测。

没有完整Windows客户端或本版实机杀怪日志，受控死亡/货币/公开接口测试不能替代客户端验证；小怪声望不能宣称彻底解决全部实机异常。小怪声望既有验证边界继续保留。每次更新同步main与downloads，不创建Release，不覆盖玩家存档，不公开用户原始日志。
