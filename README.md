使用：退出游戏，备份存档及原 Lib/game.res，将玩家包 Lib 文件夹覆盖到游戏目录。

灵符咒可在佣兵死亡、实体已消失时领取：角色份额立即到账，佣兵份额保留到复活出战、原经验恢复后补发。未到账部分保留，不重复领取或补发。活着时累计和正常经验分配保持，不额外扣除角色正常经验。游戏显示魔改版 1.206；既有配色和其他玩法保持。
