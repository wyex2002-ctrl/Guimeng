玩家下载 `归梦v2.26_魔改补丁_v1.212.zip`；维护包 `Guimeng_v1.212_maintenance.zip` 用于开发。

使用：退出游戏，备份存档及原 Lib/game.res，将玩家包 Lib 文件夹覆盖到游戏目录。
排查问题：游戏闪退时，请将 log 文件夹中的日志文件一起提供；重启后上一轮日志见 previous。

V键地图及共用的大地图出口旁显示目的地名称。优先上方，空间不足或与邻近出口名称冲突时尝试下/左/右，避让边缘、标题和坐标区；窄视图可折行。保留原有圆点配色、地图操作和传送条件；迷阵按当前进度只读预览目的地，不触发传送或修改计数。战斗手感、伤害、攻速/CD和211剑光保持。游戏显示魔改版 1.212。

正常/hot相关专项通过：完整原生地图构造/图片设置/标记注册/渲染回调及最终显示，实际字体创建导出链；99个现有传送标记目的地、真实固定传送分派、迷阵只读预测、边角/邻近/缩放平移/窄图/大图、隐藏/重复/切图及200代表帧缓存。四个神舰对话入口静态核对原子树目的地。原标记坐标与颜色调用序列对211保持，两包ZIP及玩家资源匹配检查通过。
