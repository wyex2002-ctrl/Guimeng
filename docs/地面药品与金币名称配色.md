# 地面药品与金币名称配色（v1.252）

金创药、魔法药（各大小、药包和Q前缀）地面名称白色#FFFFFF；金币淡黄#FFE7A0。当前资源共22种药品/药包与5种金币，全部来自12/4090原模板清单。

仅覆盖地面对象名称标签的颜色参数。原物品颜色字段和公共模板不改，背包/商店颜色、图标、药效、价格、叠加数量与金币数额不变；其他物品及装备品质原描边保持。

`ground_name_color_v252.lua`只读物品内部名称和原分类/子类。道具/消耗品中的金创药_、魔法药_族（可带Q前缀）和同名基础项为白；特殊分类中的金币_族/金币为淡黄，其他返回原色。原76构造器完整执行，在标签颜色计算结束后调用私有子闭包，保留R6～16尤其R15品质，使用R17～19临时槽。回到原447继续取描边、尺寸再置标题。未向公开Sys或数据库增加API。

回归运行新旧完整构造器与原只读Sys包装，图形/地图/字体/窗口基本原语有限。22药/5金币的数量1/9与描边开关均验证，检查输入物品颜色未改；其他药/祝福油/相似名、0～7品质与200次代表构造保持原值。未做Windows真实像素和全资源动画实测。
