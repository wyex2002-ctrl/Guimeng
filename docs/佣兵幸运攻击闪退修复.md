# 佣兵幸运攻击闪退（v1.248）

上传的新错误记录明确指向佣兵攻击回调12/18008调用合并幸运助手，math.max收到字符串后退出。246记录已经出现同样错误，因此本次没有撤销247的翔空或间距修改。

原R11/R12初始化为0，随后被装备、元素文字键和被动概率复用。调用技能的可选最小/最大伤害为空时，没有重新建立默认值；抽中幸运后math.max用到“防火元素”等文字就报错。旧测试截取攻击片段并注入数字2/4，遗漏了此前真正的元素/装备分支。

修复只在该回调原385前补两条指令：R11=0、R12=0，然后继续执行原技能配置覆盖。与主角伤害路径的同类初始化一致。元素伤害已在R18算完，不会清掉；技能配置的显式上下限仍有效，倍率、幸运规则、伤害公式及其他已完成功能保持。

完整旧回调加真实公开佣兵属性/原随机包装/实际幸运助手，复现字符串错误及无元素的nil/装备表错误。新回调严格要求随机数上下限是number，通过全部七元素、幸运0～7、抽中/未中、配置覆盖和200次代表调用。配置边界另用明确合成配置测试；引擎整数是有限接口，旧负对照模拟观察到的非数值输入能返回数值的行为以到达max错误，不能当作Windows引擎内部转换验证。

没有改幸运助手、概率或26角色模块；未做Windows长时间战斗、完整图形与退出读档实测。上传日志不随包公开。
