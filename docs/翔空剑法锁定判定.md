# 翔空剑法锁定判定（v1.247）

自动出手时保存传入的原敌人引用，在原生收集完翔空的范围目标后，补充这个原锁定目标的一次伤害判定。目标已移动到范围之外也适用；没有原目标时仍按原生格子规则。

目标必须仍有id、未消失、有效、可选、属于本次敌方，且生命是有效正数。死亡、消失、无效或转为友方不会补判；后续切换锁定也不会把该击转给新目标。已被原格子找到时保留原伤害比例，仅删除该目标的重复条目；缺失时追加100%比例。命中、护甲、伤害与元素仍由原游戏流程计算，一次判定不等于必中。

八个朝向的原5格与50/80/100比例不改，不追加地图查询，不平移攻击范围。其他单位的原顺序、比例和重复项不动。原冷却、费用、蓄力、动作、剑光和伤害时间保持。

实现：26/54在自身范围技能改锚点之前，扩展原刺杀目标保存条件到翔空，保留私有__gm_cisha_target_v139字段名兼容已有代码；26/53原1347格子收集边界先调用主角已有__gm_melee_timing_v208的locked_hit分支，再执行旧刺杀合并/特效/伤害。逻辑源码maintenance/melee_timing_v247.lua，官方LuaJIT2.0编译后仍单原型替换26/87。构造及刷新插入点在maintenance/patch_v247.py，跳转重定位和A活跃边界逐项验证。26/51与55不动。
