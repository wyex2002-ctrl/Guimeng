# 祝福油与幸运系统（v1.248）

## 当前规则与使用对象

- 主角使用自己装备累计的有效幸运；佣兵使用自己装备累计的有效幸运，包含其坐骑，不叠加主角幸运，也不重复加一次坐骑。
- 主角召唤物读取主角幸运；佣兵召唤物读取佣兵幸运。按真实主人id关系解析，拒绝无主、循环或异常关系，不按名字匹配。
- 主角背包右键、角色物品快捷栏：强化主角坐骑。佣兵背包（原生333～396格）右键：强化佣兵坐骑。
- 幸运0必定升到1；幸运1～6为40%升1、30%降1、30%不变；有效使用扣1瓶，上限7。无坐骑或已达7不消费。
- 佣兵未出战但装备控件仍存在时，直接修改其持久坐骑实例；有绑定实体则立即更新，没有实体则原生再次绑定装备时累计。不会回退到主角坐骑。

原佣兵背包右键是将道具移回主角背包。此次只为祝福油跳过该转移事件，交由原库存Main和消费链执行；其他道具仍按原行为。祝福油仍可正常拖动转移。

角色物品快捷栏沿原引用机制：前尘忆梦1～6、来世续缘21～26格。快捷引用调用原“按名称使用物品”去主角背包找到实物，扣一瓶，引用自身不扣。无实物时明确拒绝使用引用本身，避免免费强化。为祝福油模板及存量附加补原快捷物品标记0，加载时重绑当前Main，防止旧脚本丢失来源格子参数。

## 概率修改位置

`maintenance/luck_rules_v246.lua`为当前集中规则文件：`equipment(context)`返回0～1小数；`enhancement(context)`返回成功、下降、不变的三项权重，运行时统一归一化；`guild_attack=0.11`保留原幸运加持。以后复杂公式修改这一个文件后重建资源即可，不需要在游戏目录另放Lua。

装备幸运X限制0～7；X=0时装备概率为0，从1开始为1/(10-X)，保留浮点精度。幸运1为约11.11%，幸运7为约33.33%。技能与状态提供的独立幸运不因装备为0而失效。攻击将本次实际技能的幸运属性/100及适用的原加持直接相加，最高1，合并后只做一次幸运判定。原幸运加持是1～100达到90，即11%。原佣兵攻击没有额外行会幸运判定，本版不借用主角行会幸运。

防御与攻击独立；原有随机物理/魔法防御共用该次防御幸运，原本固定使用最大防御的分支继续固定。成功时用原随机区间的较大端，后续原伤害、元素、命中、暴击、减伤、三攻/双防合计公式均保持。最终随机本身也可能抽中上限，不能把最大值出现率当幸运触发率。

规则context含luck、actor/owner、skill、kind；强化另有item、source、companion。未出战佣兵的强化owner可能为空，但物品实例、来源格子和companion仍有效，未来复杂公式须考虑这种情况。
